# 015 — Google sign-in and sessions

**Status:** done · **Plan:** [Plan 0002](../plans/0002-google-sign-in.md) · **Depends on:** 014

## Goal

Sign in with Google's button; the Worker checks the ID token and keeps a session.

## Done when

- [x] Google Identity Services button on My plan
- [x] `POST /api/auth/google` checks the token with `jose` (signature, issuer, audience, expiry)
- [x] Sessions: random token, hashed in D1, `__Host-session` cookie (HttpOnly, Secure, SameSite=Lax, 30 days)
- [x] `POST /api/auth/signout`; rate limit on sign-in; Origin check on writes

## Notes

**Waiting on you:** the Google OAuth client ID.

Built on November 3 with client ID `316564590500-t9tg….apps.googleusercontent.com`.

- **Button:** Google's button sits on My plan (`src/components/Account.astro`),
  loading Google's script only there, in popup mode with FedCM. Preview links
  show a note instead, because Google accepts only `afrotech26.laudebugs.me`
  and `localhost`.
- **Token check:** `POST /api/auth/google` checks the ID token with `jose`
  (6.2.12, pinned) against Google's published keys: signature, issuer, audience
  and expiry. It then upserts the user by `sub` and starts a 30-day session in
  the `__Host-session` cookie (`HttpOnly`, `Secure`, `SameSite=Lax`), storing only
  the token's hash.
- **Protections:** a rate limit of 10 sign-in attempts per minute per IP
  (`SIGNIN_LIMITER`), and an Origin check plus JSON body on every write.
- **Types:** the Worker now uses types generated by `wrangler types`
  (`npm run types`) instead of `@cloudflare/workers-types`, whose current release
  conflicted with Wrangler's peer requirement.
- **Tested locally** with a test signing key in `.dev.vars` (never deployed;
  production always uses Google's keys):
  - a good token signs in, and `/api/me` knows the user
  - a wrong audience, wrong issuer, expiry or garbage gets 401, and a missing
    Origin gets 403
  - sign-out ends the session, and the 11th rapid attempt gets 429

  Google's real button renders on the page. **Not tested:** a real Google
  account signing in, which needs the live site.
