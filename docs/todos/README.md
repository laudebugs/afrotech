# To-dos

Tasks for Claude to pick up, one file each. Ask for one by number ("do todo 003").

## Format

```md
# NNN — Title
**Status:** todo | doing | done · **Plan:** link · **Depends on:** NNN

## Goal
## Done when
- [ ] checklist
## Notes
```

When a todo is finished, set **Status: done**, tick the checklist and add a
short note on anything that changed from the plan.
